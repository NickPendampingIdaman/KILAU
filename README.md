# KILAU
KILAU (Kilas Informasi Akademik Terpadu) adalah website perpustakaan digital OSIS SMA Labschool Ciracas. Platform ini menyediakan catatan materi, video belajar, dan info lomba yang dirilis seminggu sebelum ujian (ATS/AAS). Dilengkapi sesi Zoom bersama guru, KILAU hadir untuk tingkatkan literasi digital dan prestasi siswa.
